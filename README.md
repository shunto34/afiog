# afiog — 製造業×転職アフィリエイト プロジェクト

製造業の本業経験を活かした転職特化アフィリエイトサイト。**最初から WordPress で立ち上げる一発勝負戦略**。

## このリポジトリの目的

- 戦略・ロードマップを言語化して、ブレずに継続する
- WordPress 記事を Markdown で書き、Git で履歴管理する
- ASP・KW・競合のリサーチメモを集約する
- ステージ2以降で必要になるツール（KW発掘スクリプト等）を保管する

## 期待値（正直版）

| 期間 | 現実的成果 | 上振れ | 下振れ |
|---|---|---|---|
| 4ヶ月 | 月数千円 | 月1〜2万 | 0円 |
| 12ヶ月 | 月3〜10万 | 月15〜30万 | 月数千円 |
| 24ヶ月 | 月10〜30万 | 月50〜80万 | 撤退判断 |

月100万は最短24ヶ月、現実的には30〜36ヶ月。「半年で月100万」を約束する情報発信は基本ポジショントーク。

## 一発勝負戦略：3ステージ

詳細は `docs/strategy.md`。

### ステージ1（0〜2ヶ月）：立ち上げ
- 初期投資 **約8,500円**（ドメイン + サーバー年契約）
- WordPress 構築、A8.net / afb 登録
- **初期10記事を投入**（指名検索3本 + 体験談7本）

### ステージ2（2〜12ヶ月）：記事拡張 + 最適化
- **月5記事ペース**で30〜50記事へ拡張
- Search Console データで勝ち記事リライト
- ラッコKWなど補助ツール検討（月660円〜）

### ステージ3（12ヶ月〜）：仕組み化判断
- 月5〜15万円が出ていれば AI下書き支援パイプラインを構築
- 出ていなければ戦略大幅見直し or 撤退

## 撤退ライン（死守）

| 時期 | 条件 | 判断 |
|---|---|---|
| 6ヶ月 | 月収益3,000円未満 + 記事数20本未満 | 記事ペース or KW戦略を再設計 |
| 12ヶ月 | 月収益3万円未満 | ジャンル拡張 or 撤退の真剣検討 |
| 18ヶ月 | 月収益10万円未満 | 撤退判断 |

## コミットライン（自分との約束）

- **6ヶ月で最低30記事**
- 月5記事の更新を1年間継続
- 戦略をコロコロ変えない（最低12ヶ月固定）
