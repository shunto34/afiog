# afiog — 製造業×転職アフィリエイト プロジェクト

製造業の本業経験を活かした転職特化アフィリエイトサイトの戦略・記事ストック・運用ツールをまとめるリポジトリ。

## このリポジトリの目的

- 戦略・ロードマップを言語化して、ブレずに継続する
- note/ブログ記事を Markdown で書き、Git で履歴管理する
- ASP・KW・競合のリサーチメモを集約する
- Phase 2 以降で必要になるツール（KW発掘スクリプト等）を保管する

## 期待値（正直版）

| 期間 | 現実的成果 | 上振れ | 下振れ |
|---|---|---|---|
| 4ヶ月 | 月数千円 | 月1〜2万 | 0円 |
| 12ヶ月 | 月3〜10万 | 月15〜30万 | 月数千円 |
| 24ヶ月 | 月10〜30万 | 月50〜80万 | 撤退判断 |

月100万は最短24ヶ月、現実的には30〜36ヶ月。「半年で月100万」を約束する情報発信は基本ポジショントーク。

## フェーズ設計

詳細は `docs/strategy.md`。

### Phase 0（0〜1ヶ月）：反応テスト
- 初期投資 **0円**
- note + X で記事3本投稿、反応で続行/撤退/ジャンル変更を判断

### Phase 1（1〜4ヶ月）：WordPress 移行 + ASP登録
- 投資 約8,500円（ドメイン + サーバー年契約）
- A8/afb 登録、案件単価を実数で把握
- 10記事を整備

### Phase 2（4〜12ヶ月）：KW発掘ツール + 記事拡張
- 30〜50記事へ拡張
- ラッコKWなど有料ツール検討（月660円〜）
- Search Console データで勝ち記事リライト

### Phase 3（12ヶ月〜）：仕組み化判断
- 月5〜15万円が出ていれば AI下書き支援パイプラインを構築
- 出ていなければジャンル切替 or 撤退
