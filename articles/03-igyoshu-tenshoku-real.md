# 工場勤務から異業種転職は本当にできるのか【製造業[N]年目が調べた結論】

## 想定読者

- 「工場の経験は他で通用しないのでは」と不安な人
- 異業種に憧れつつ年齢で諦めかけている人
- 過去に転職活動して挫折した経験のある人

## 構成案（6ブロック）

### ① 結論先出し

- 結論：[YES/条件付きYES/NO のいずれか]
- 理由を3行で要約
- この記事で扱う異業種：営業職・IT職・サービス業・公務員系

### ② なぜ「製造業から異業種は無理」という説が広がっているか

- ネット上の言説の整理
- 実際の転職市場との乖離ポイント
- 「無理説」を流す人のポジショントーク分析

### ③ 異業種転職に評価される製造業スキル（情報ブロック）

具体スキル5つ：
- 品質管理・PDCAサイクルの実体験 → どの業界でも通用
- 設備保全・トラブルシュート力 → IT職で評価
- 多能工としてのマルチタスク → サービス業で評価
- 安全管理意識 → 建設・物流で評価
- チームリーダー経験（班長等） → 営業マネジメントで評価

→ それぞれ「なぜ評価されるか」「どう履歴書に書くか」のセットで。

### ④ 異業種転職で失敗する人のパターン

- 年収にこだわりすぎて未経験スタートを拒否する
- 業界研究せず憧れだけで応募する
- 製造業のスキルを「謙遜しすぎて」アピールできない
- エージェントを1社しか使わない
- 年齢を言い訳にして動かない

### ⑤ 実際に動く順序（実践ブロック）

1. 自分の市場価値を知る（[サービス名]で査定）
2. 転職エージェント2〜3社に登録（総合系 + 業界特化系）
3. 履歴書・職務経歴書を業界別に書き分ける
4. 在職中に動く（退職してから動かない）
5. 内定が出てから現職と比較する

→ Phase 1 でここに具体的なASPリンクを差し込む

### ⑥ まとめ + 次回予告

- 結論再掲
- 次回予告：「メーカー転職エージェント[X社] vs [Y社]」（指名検索系・即金記事）
