## なぜ「製造業×転職」を選ぶか

### 勝てる構造的理由

1. **E-E-A-T で AI 量産記事に勝てる**
   現役製造業勤務者の体験談は、AI 生成記事では再現できない。Google の Helpful Content System 以降、一次情報の有無が順位を決める。

2. **専業アフィリエイターの参入が中程度**
   看護師転職・エンジニア転職は専業でレッドオーシャン。製造業転職はそれらより薄い。完全にガラ空きではないが、副業初心者でも食い込む隙間がある。

3. **副業との親和性が高い**
   通勤・休憩時間にネタが湧く。記事ネタのリサーチコストが他ジャンル比でほぼゼロ。

4. **指名検索系の即金記事が書ける**
   「工場ワークス 評判」「タイズ メイテックネクスト 比較」など、登録/比較系は競合最少 × CVR 最高。Phase 1 の初収益はここから出る想定。

### 構造的限界（直視する）

- **市場サイズが中程度**：看護師転職検索ボリュームの 1/10 程度
- **単一サイトで月100万到達した事例はほぼ無い**：月30万が現実的天井
- **月100万には隣接ジャンル拡張が必要**（夜勤者の健康・副業・投資など）

## なぜ「Phase 0」から始めるか

WordPress 構築 + ドメイン取得 + ASP 登録を最初にやると、副業初心者の 95% がここで止まる。
初期投資ゼロの note/X で反応を見てから本格投資する方が、失敗コストが圧倒的に低い。

### Phase 0 の判定基準

- 3記事中1本でも note スキ 20+ / X インプレ 5,000+ → Phase 1 進行
- 全部反応薄い → ジャンル変更を真剣に検討（金銭損失ゼロ）
- 記事を書く行為自体が苦痛 → アフィリエイト撤退を検討

## 元X投稿（@TensyokuRmla）への評価

参考にした投稿の主張：「Codex で自動化すれば月100万」

| 主張 | 評価 |
|---|---|
| 高単価ASPに絞る | ◎ 正しい |
| Codex で KW 発掘 | ○ Phase 2 で有効 |
| ChatGPT で 2,500字 LP 量産 → WordPress 自動下書き | ✕ 編集なしは Helpful Content System で死ぬ |
| Clarity API でヒートマップ自動分析 | ○ Phase 3 で有効 |
| ASP管理画面の定期スクレイピング | ✕ A8 等は規約違反、垢BANリスク |
| 「成約3件/日 = 月135万」試算 | △ 上位1%の上振れシナリオ |
| 「Codex 使ってる時点で上位1%」 | ✕ 2026年時点で完全に古い認識 |

→ コアアイデア（高単価ASP特化・KW発掘の自動化・ヒートマップ分析）は妥当。
   ただし「全自動・短期間で月100万」は誇張。
