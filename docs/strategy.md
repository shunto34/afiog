# 全体戦略

## 前提条件（自分のスペック）

- アフィリエイト経験：ゼロ
- 本業：製造業
- 稼働時間：週数時間（本業ありの副業）
- 初期資金：2〜3万円
- 目標：最終的に月100万円。ただし現実的タイムラインで。
- スタンス：**一発勝負**。note でのテストフェーズは省略。

## なぜ「製造業×転職」を選ぶか

### 勝てる構造的理由

1. **E-E-A-T で AI 量産記事に勝てる**
   現役製造業勤務者の体験談は、AI 生成記事では再現できない。Google の Helpful Content System 以降、一次情報の有無が順位を決める。

2. **専業アフィリエイターの参入が中程度**
   看護師転職・エンジニア転職は専業でレッドオーシャン。製造業転職はそれらより薄い。完全にガラ空きではないが、副業初心者でも食い込む隙間がある。

3. **副業との親和性が高い**
   通勤・休憩時間にネタが湧く。記事ネタのリサーチコストが他ジャンル比でほぼゼロ。

4. **指名検索系の即金記事が書ける**
   「工場ワークス 評判」「タイズ メイテックネクスト 比較」など、登録/比較系は競合最少 × CVR 最高。ステージ1の初収益はここから出る想定。

### 構造的限界（直視する）

- **市場サイズが中程度**：看護師転職検索ボリュームの 1/10 程度
- **単一サイトで月100万到達した事例はほぼ無い**：月30万が現実的天井
- **月100万には隣接ジャンル拡張が必要**（夜勤者の健康・副業・投資など）

## なぜ「一発勝負」を選ぶか

二段構え（note でテスト → WordPress 本格運用）はリスク低いが、副業者は段階移行のたびに離脱しやすい。
ジャンル選定が「製造業×転職」で確定している以上、テスト期間は不要と判断。

ただし**一発勝負には覚悟が必要**：

- ジャンル相性のテストなしで 8,500円投資する
- 反応データなしで KW を選ぶ → ASP単価とSEO検索ボリュームから論理的に組む
- 書く筋肉ができてない状態で月5記事ペースを維持する
- 「合わなかった」のリカバリーがきかない

→ だからこそ「6ヶ月30記事」を最初に握る。これを守れない自分なら、そもそも別ジャンルでも勝てない。

## 元X投稿（@TensyokuRmla）への評価

参考にした投稿の主張：「Codex で自動化すれば月100万」

| 主張 | 評価 |
|---|---|
| 高単価ASPに絞る | ◎ 正しい |
| Codex で KW 発掘 | ○ ステージ2で有効 |
| ChatGPT で 2,500字 LP 量産 → WordPress 自動下書き | ✕ 編集なしは Helpful Content System で死ぬ |
| Clarity API でヒートマップ自動分析 | ○ ステージ3で有効 |
| ASP管理画面の定期スクレイピング | ✕ A8 等は規約違反、垢BANリスク |
| 「成約3件/日 = 月135万」試算 | △ 上位1%の上振れシナリオ |
| 「Codex 使ってる時点で上位1%」 | ✕ 2026年時点で完全に古い認識 |

→ コアアイデア（高単価ASP特化・KW発掘の自動化・ヒートマップ分析）は妥当。
   ただし「全自動・短期間で月100万」は誇張。

## 初期10記事の構成計画

**設計方針（2026-05-24 シミュレーションを受けて修正済）**：
- AI Overview（AIO）で死ぬビッグKW（「製造業 転職」「メーカー 転職」単体）は**狙わない**
- 指名検索 × 比較 × 体験談 の3本柱に集中
- 内部リンクで指名検索記事に流入を集約する設計

### 指名検索系（即金・本命）3本

CVR最高、上位表示しやすい、AIO影響が小さい。

1. 「メイテックネクスト 評判」
2. 「タイズ 評判 メイテックネクスト 比較」
3. 「工場ワークス 評判」

### 体験談系（SEO狙い・E-E-A-T差別化）4本

「悩み系KW」で AI 量産記事に対する差別化要素となる。

4. 製造業[N]年の私が転職を真剣に検討した話
5. 夜勤がしんどくて転職を考えた話
6. 工場勤務から異業種転職は本当にできるのか
7. メーカー転職で年収アップした人の共通点

### 集約系（指名検索の受け皿）3本

ビッグKW狙いではなく、**指名検索記事への内部リンク集約**として機能させる。

8. 製造業向け転職エージェント比較【2026年版】（指名検索3本へリンク）
9. 工場勤務からの転職先カタログ（体験談記事へリンク）
10. 製造業の市場価値はどう測るか（汎用エージェント案件への導線）

`articles/` には現状3本の骨子があるので、残り7本の骨子はステージ1で追加する。

## 隣接ジャンル拡張計画（Day 1 から組み込む）

シミュレーション結果、月100万到達には製造業転職単体では不足（天井 月30万）。
**WordPress のカテゴリ設計を最初から拡張前提で組む**：

| カテゴリ | 展開時期 | 主要ASP案件例 |
|---|---|---|
| ① 製造業転職（本丸） | ステージ1〜 | メイテック / タイズ / doda |
| ② 夜勤・交代勤務（健康・対策） | ステージ2前半 | 健康食品 / 睡眠グッズ / 退職代行 |
| ③ 製造業×副業 | ステージ2後半 | プログラミングスクール / 投資系 |
| ④ 退職・キャリアチェンジ全般 | ステージ2後半 | 退職代行 / 転職全般エージェント |

カテゴリ①②は記事内で自然に内部リンクできる（「夜勤がしんどい」→「日勤転職」）。
ステージ1ではカテゴリ① + ② の入口記事のみ作成。
