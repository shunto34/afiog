## 開始時点での約束（2026-05-24）

- 月100万は **最短24ヶ月**、現実的には30〜36ヶ月。半年で焦らない。
- ジャンルは「製造業×転職」で確定。**3ヶ月は他ジャンルに浮気しない**。

## アンチパターン集（自分が陥りやすい罠）

### 罠①：ノウハウコレクター化
- 新しいアフィリ系インフルエンサーの発信を見て、戦略をコロコロ変える
- → ルール：**Phase 終了まで戦略変更しない**。気になったノウハウはこのファイルにメモするだけ。

### 罠②：完璧主義で公開遅延
- 「もう少し推敲してから」で記事公開が遅れる
- → ルール：**60%の完成度で公開、後でリライト**。Phase 0 はスピード優先。

### 罠③：ツール作りに逃げる
- 記事書くのが面倒になって、KW発掘ツールの実装に時間を使う
- → ルール：**Phase 2 までツール作らない**。Phase 1 で月収益0円なら、ツール作っても結果出ない。

### 罠④：AI生成記事の量産誘惑
- Claude/ChatGPT で 10記事を1日で量産したくなる
- → ルール：**1記事に最低3時間の人間編集**。体験談・数字・固有名詞は手書き。

### 罠⑤：他人と比較
- 「半年で月50万」みたいなXポストに焦る
- → ルール：**自分のデータだけ見る**。他人の成功体験の99%は再現性ゼロ。
