# 自分への戒め・学びログ

迷ったとき・モチベ落ちたときに読み返す用。

## 開始時点での約束（2026-05-24）

- 月100万は **最短24ヶ月**、現実的には30〜36ヶ月。半年で焦らない。
- ジャンルは「製造業×転職」で確定。**12ヶ月は他ジャンルに浮気しない**。
- **6ヶ月で30記事**、これを死守する。これを守れないなら別ジャンルでも勝てない。
- 一発勝負を選んだ以上、撤退ラインに到達するまで戦略を変えない。
- 「Codex で全自動・月100万」系の煽り投稿に振り回されない。
- 1記事に自分の体験・数字・固有名詞を最低1つは入れる。

## 一発勝負を選んだ理由（忘れない）

二段構え（note でテスト → WordPress 本格運用）を退けた理由：

- 段階移行のたびに副業者は離脱する
- ジャンルが「製造業×転職」で確定している以上、テスト期間は時間の無駄
- 「めんどくさい工程」を増やすと続かない

**裏返し**：一発勝負を選んだ以上、「やっぱり合わなかった」「やる気が出ない」は通用しない。
撤退ラインに達するまで手を止めない。

## アンチパターン集（自分が陥りやすい罠）

### 罠①：ノウハウコレクター化
- 新しいアフィリ系インフルエンサーの発信を見て、戦略をコロコロ変える
- → ルール：**ステージ完了まで戦略変更しない**。気になったノウハウはこのファイルにメモするだけ。

### 罠②：完璧主義で公開遅延
- 「もう少し推敲してから」で記事公開が遅れる
- → ルール：**70%の完成度で公開、後でリライト**。リライト前提で動く。

### 罠③：ツール作りに逃げる
- 記事書くのが面倒になって、KW発掘ツールの実装に時間を使う
- → ルール：**ステージ2までツール作らない**。ステージ1で記事10本出してないのにツール作るのは現実逃避。

### 罠④：AI生成記事の量産誘惑
- Claude/ChatGPT で 10記事を1日で量産したくなる
- → ルール：**1記事に最低3時間の人間編集**。体験談・数字・固有名詞は手書き。

### 罠⑤：他人と比較
- 「半年で月50万」みたいなXポストに焦る
- → ルール：**自分のデータだけ見る**。他人の成功体験の99%は再現性ゼロ。

### 罠⑥：撤退ラインの後ろ倒し
- 6ヶ月で月3,000円未満なのに「あと3ヶ月待てば」と先延ばし
- → ルール：**撤退ラインは契約。後ろ倒ししない**。判断が必要なときに判断する。
