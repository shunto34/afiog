### 判定（Week 4 末）

3本投稿後の反応を以下で評価：

| 指標 | 進行 | 要再考 | 撤退 |
|---|---|---|---|
| note 最高スキ数 | 20以上 | 5〜19 | 5未満 |
| note 最高閲覧数 | 500以上 | 100〜499 | 100未満 |
| X 最高インプレ | 5,000以上 | 1,000〜4,999 | 1,000未満 |
| X フォロワー増 | 30以上 | 10〜29 | 10未満 |
| 自分の継続意欲 | 書きたいネタが10個以上湧く | やや義務感 | 苦痛 |

- **3つ以上「進行」**：Phase 1（WordPress 構築 + ASP 登録）へ
- **「要再考」中心**：ジャンルを部分修正（製造業×別軸）して Phase 0 をもう1ヶ月
- **「撤退」中心**：ジャンル変更 or アフィリエイト以外の選択肢を再検討

## やってはいけないこと

- ❌ Phase 0 でドメイン取得・サーバー契約（金銭損失リスク）
- ❌ Phase 0 で ASP 登録（記事数 0 で登録すると審査落ちの履歴がつく）
- ❌ ChatGPT/Claude で記事を丸ごと生成 → そのまま投稿（自分の体験が薄れて差別化要素ゼロ）
- ❌ AdSense や他広告の貼り付け（note は不可、X は意味ない）
- ❌ 「いきなりバズ狙い」のタイトル（過度な煽りは長期信頼を毀損）

## やるべきこと

- ✅ 数字・固有名詞・年代を具体的に書く（年収、メーカー名はぼかしてOK）
- ✅ 失敗体験・後悔エピソードを必ず入れる（共感の起点）
- ✅ 各記事の最後に「次に書く予定の記事」を予告（リピート読者作り）
- ✅ X では記事告知だけでなく、日常の気づき・ぼやきも混ぜる（人間味）
- ✅ Claude/ChatGPT は「構成案出し」「言い回しブラッシュアップ」用に使う（補助輪）
