# 記事公開ワークフロー

**前提**：`articles/XX-xxx.draft.html` の HTML ドラフトが存在する状態から、WordPress に記事を公開するまでの手順。

**所要時間目安**：1記事あたり 2.5〜3.5時間（うち体験談執筆 1〜2時間）

---

## ステップ0：公開前チェック（5分）

公開する前に、以下が完了しているか確認。

- [ ] ドメイン取得済み
- [ ] ConoHa WING サーバー契約済み
- [ ] WordPress 管理画面にログインできる
- [ ] テーマ（Cocoon 推奨）導入済み
- [ ] Rank Math SEO プラグイン有効化済み
- [ ] Google Search Console 連携済み
- [ ] A8.net / afb 登録済み（指名検索記事の場合は該当ASPリンク取得済み）
- [ ] WordPress カテゴリ作成済み（製造業転職 / 夜勤・交代勤務 / 製造業×副業 / 退職・キャリアチェンジ）

未完了の項目があれば `docs/launch-checklist.md` の Week 1 に戻る。

---

## ステップ1：プレースホルダーを埋める（1〜2時間）

**ここが記事の価値の80%を決める工程。手を抜くと公開する意味がない。**

### 1-1. HTMLドラフトをエディタで開く

`articles/02-yakin-tsurai-tenshoku.draft.html` のような ドラフトファイルを VS Code / メモ帳 等で開く。

### 1-2. ファイル冒頭の【人間が埋める箇所】コメントを確認

`<!-- -->` 内に埋めるべきプレースホルダー一覧がある。全て埋まるまで公開しない。

### 1-3. 体験談ブロックを書く（最重要）

`[HEALTH_EPISODE]` `[REGRET_EPISODE]` などの体験談プレースホルダーは、**200〜400字の自分の言葉**で埋める。

書くときのコツ：
- **時間・場所・行動を具体に**：「先月の連休、息子の運動会に行けなかった」（◎） vs 「家族との時間が減った」（✕）
- **数字を入れる**：「夜勤明けの土曜、気づいたら15時まで寝ていた」
- **感情を1つだけ書く**：書きすぎると押しつけがましい
- **会社名・部署名・地名は伏せる**：「[INDUSTRY]系の工場」程度の解像度で

### 1-4. 数値系プレースホルダーを埋める

- `[AGE]` `[YEARS]`：自分の実数
- `[YAKIN_TEATE_AMOUNT]`：差し障りない範囲で（多少ぼかしてOK）
- `[INDUSTRY]`：業界名（「自動車部品」「食品」「精密機器」程度のぼかし）
- `[SHIFT_PATTERN]`：「2交代制」「3交代制」「夜勤専従」など

### 1-5. ファイル末尾の `[YEAR][MONTH]` を当月に更新

`※本記事は2026年5月時点の情報です` のような表記。

### 1-6. セルフチェック

- [ ] `grep -n "\[" articles/XX.draft.html` で残プレースホルダーが ASP/内部リンク系だけになっているか確認
- [ ] 体験談ブロックが「他の誰でも書ける一般論」になっていないか
- [ ] 固有名詞（伏せ字含む）が3つ以上あるか

## ステップ2：WordPress で新規投稿を作成（5分）

### 2-1. 投稿 → 新規追加
管理画面の左メニュー「投稿 → 新規追加」。

### 2-2. タイトルを入力
HTML の `<h1>` の中身をコピー → タイトル欄に貼る。
**注意**：本文には `<h1>` を含めない（タイトル欄が自動的に H1 になる）。

### 2-3. カスタムHTMLブロックを追加
「+」ボタン → 「カスタム HTML」ブロック選択。

### 2-4. HTML を貼り付け
ドラフトから `<h1>` 行を除いた本文をコピー → カスタムHTMLブロックに貼り付け。

### 2-5. プレビューで表示確認
ブロック右上の「プレビュー」で見出し階層・表組み・リストが崩れていないか確認。

## ステップ3：リンクを実URLに置換（10〜15分）

### 3-1. ASP リンクを置換

| プレースホルダー | 置換先 |
|---|---|
| `[ASP_LINK_MEITECH]` | A8.net のメイテックネクスト リンクコード |
| `[ASP_LINK_TAIZ]` | A8.net のタイズ リンクコード |
| `[ASP_LINK_KOJO_WORKS]` | A8.net の工場ワークス リンクコード |
| `[ASP_LINK_TAISHOKU]` | A8.net の退職代行 リンクコード |
| `[ASP_LINK_DODA]` | A8.net の doda リンクコード |

**ASP リンクの取り方**：
1. A8.net 管理画面 → 該当案件 → 「広告リンク作成」
2. 「テキスト広告」を選択
3. リンクコード（`<a href=...>` 全体）をコピー
4. ドラフトの `<a href="[ASP_LINK_XXX]">テキスト</a>` の `<a>` タグごと置換

**重要**：A8 のリンクには `rel="nofollow noopener"` が自動付与される。これは外さない。

### 3-2. 内部リンクを置換

| プレースホルダー | 置換先 |
|---|---|
| `[INTERNAL_LINK_KOJO_TENSHOKU]` | 記事①「製造業N年の私が転職検討した話」のURL |
| `[INTERNAL_LINK_IGYOSHU]` | 記事③「異業種転職できるのか」のURL |

**注意**：まだ該当記事が公開されていない場合、その内部リンクごとコメントアウト or 文章再構成。空リンクは絶対NG。

## ステップ4：アイキャッチ画像を作成・設定（15〜20分）

### 4-1. Canva 無料版でアイキャッチを作る
- テンプレート：「ブログ アイキャッチ」検索 → 1280×720 サイズ
- 文字入れ：タイトルの短縮版（例：「夜勤がしんどい人へ」）
- 画像：Canva 内の無料素材で「工場」「夜」「ビジネスマン」などを検索
- **著作権**：Canva 内の無料素材以外は使わない（フリー素材サイトは別途ライセンス確認）

### 4-2. WordPress にアップロード
投稿画面右サイドバー「アイキャッチ画像」→ 「アイキャッチ画像を設定」→ アップロード。

### 4-3. 画像 alt 属性を設定
アップロード時に「代替テキスト」欄に記事内容を一言（例：「夜勤明けの工場員」）。SEOで地味に効く。

## ステップ5：SEO 設定（Rank Math、5〜10分）

投稿画面下部に Rank Math の設定欄がある。

### 5-1. SEO タイトル
デフォルトは記事タイトル + サイト名。文字数 60字以内 になるよう調整。
例：`夜勤がしんどい人が読むべき記事【製造業10年目のリアル】 | サイト名`

### 5-2. メタディスクリプション
**120〜160字**で記事の要約 + クリックしたくなる文言。

テンプレート例：
```
製造業[YEARS]年目の現役勤務者が、夜勤手当に隠された本当のコストと、日勤転職という選択肢を実体験ベースで解説。健康・時間・人間関係の観点から、今後のキャリアを考える材料に。
```

### 5-3. フォーカスキーワード
記事の主要KW（例：「夜勤 つらい」）を入力。
Rank Math が KW の使用箇所をスコアリングしてくれる。**80点以上**を目安に調整。

## ステップ6：パーマリンク・カテゴリ・タグ（5分）

### 6-1. パーマリンク（URL）
投稿画面右サイドバー「URL」欄。
**英数字スラッグ**に変更（日本語URLは避ける）。

例：
- `yakin-tsurai-tenshoku`
- `meitech-next-review`
- `kojo-igyoshu-tenshoku`

### 6-2. カテゴリ
strategy.md で決めた4カテゴリのいずれかを選択：
- 製造業転職
- 夜勤・交代勤務
- 製造業×副業
- 退職・キャリアチェンジ

**1記事 = 1カテゴリ**（複数カテゴリ付けない、SEO評価が分散する）。

### 6-3. タグ
3〜5個まで。例：「夜勤」「交代勤務」「転職」「製造業」「健康」。
タグの乱用はサイト構造を汚すので控えめに。

## ステップ9：Google Search Console でインデックス申請（3分）

### 9-1. Search Console を開く
[https://search.google.com/search-console](https://search.google.com/search-console)

### 9-2. 公開した記事のURLを上部検索バーに入力
「URL検査」が走る。

### 9-3. 「インデックス登録をリクエスト」
ボタンをクリック。数分〜数日でインデックスされる。

**重要**：これをやらないと、新規ドメインは1〜2週間インデックスされない場合がある。

## トラブルシューティング

### Q. 表組みが崩れる
A. Cocoon の場合、カスタムHTMLブロック内の `<table>` はテーマCSSが当たらない。`<table class="cocoon-block-table">` のようにクラス指定するか、Cocoon の「表（テーブル）」ブロックを使う。

### Q. 内部リンクのURLが分からない
A. 該当記事を WordPress 管理画面で開き、URL欄をコピー。まだ公開していない記事へのリンクは、その記事公開時に遡って追加する（`docs/lessons.md` にメモ）。

### Q. アイキャッチが思いつかない
A. Canva の「ブログ アイキャッチ 工場」検索で出てくるテンプレを丸ごと使う。最初の10記事は凝らない。

### Q. ASPリンクが見つからない
A. A8.net の「プログラム検索」で案件名を検索。提携が「未提携」なら申請。提携承認まで1日〜1週間かかる場合あり。

### Q. 「インデックス登録をリクエスト」がエラー
A. URL検査の結果が「URL は Google に登録されていません」と出てから数分待ってリクエスト。連続申請は制限あり。

## 慣れたら短縮できるポイント

最初の3記事は手順通り丁寧に。4記事目以降は以下を短縮：

- アイキャッチ：1つのテンプレを使い回す（色だけ変える）→ 5分
- SEOタイトル/メタ：テンプレ化 → 2分
- X告知：定型文化 → 3分

**慣れれば公開作業（ステップ2〜10）は30〜45分で終わる**。
体験談執筆（ステップ1）は短縮できない。ここが記事の価値。
